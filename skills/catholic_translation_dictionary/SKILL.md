# Catholic Translation Dictionary Skill

## 使用規則

1. 本字典供天主教繁體中文翻譯使用。
2. 翻譯時須優先套用完整詞組，再套用單字。
3. 若同一英文詞有多個譯名，依上下文選擇最合適者。
4. 若原文大小寫不同但語境相同，可依上下文套用。
5. 不要將本字典中的天主教譯名替換為新教慣用語。
6. 若遇到聖經人物、地名、節日、教會術語，須優先使用本字典譯名。
