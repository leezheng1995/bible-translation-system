# Bible Translation System

A local AI-assisted Bible translation workflow system.

## Tech Stack

- FastAPI
- Docker Compose
- Redis
- SQLite
- Celery
- Ollama
- Qwen / Gemma
- Skill-based translation workflow

## Roadmap

This project follows a 30-day roadmap:
1. Docker environment
2. FastAPI core API
3. Translation workflow and skills
4. Review loop, testing, and delivery
